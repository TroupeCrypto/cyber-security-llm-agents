🚀 Deploy Your Own

  1. Fork the repository on GitHub.
  2. Go to vercel.com/new and import your forked repository.
  3. Set the required environment variables in the Vercel project settings (see below).
  4. Deploy! Vercel will automatically build and deploy the project.

⚙️ Environment Variables

VariableDescriptionStatus
OPENAI_API_KEY Your OpenAI API key Required
OPENAI_MODEL_NAME Model to use (default: gpt-3.5-turbo-0125) Optional
CALDERA_SERVER Caldera C2 server URL Optional
CALDERA_API_KEY Caldera API key Optional
